# GURPS Item Sheet: Modern

Модуль для Foundry VTT, который:

1. приводит окно предмета (Foundry Item) системы **GURPS 4e** к визуальному языку
   современного листа персонажа — того же, что используется в листе **Modern**;
2. добавляет учёт **боезапаса** для оружия с дальней атакой: автоматические
   счётчики ресурсов, списание выстрелов при атаке, тип боеприпаса, привязку
   к предмету-запасу патронов и ручное редактирование
   текущего/максимального запаса в листе персонажа.

Визуальная часть **не меняет функционал** листа предмета: шаблон, обработчики,
drag & drop, расчёт полей и сохранение данных остаются системными.

## Что делает модуль

### Визуальная часть

- Перекрашивает окно предмета в палитру Modern-листа (`--ms-*` из `gurps.css`):
  фон, карточки, рамки, текст, акцентный зелёный.
- Приводит типографику к Modern-листу: Roboto, размеры `--ms-font-*`,
  заголовки секций — uppercase с muted-цветом.
- Заменяет яркие цветные плашки типов предметов на нейтральный modern-header
  с акцентной иконкой:
  - equipment и skill — зелёный акцент;
  - feature — синий (`--ms-fp`);
  - spell — красный (`--ms-disadvantage`).
- Стилизует поля, чекбоксы, табы, кнопки добавления, кнопки удаления,
  блок изображения, скроллбары.
- Включает **штатный ресайз окна Foundry** (система отдаёт лист с
  `resizable: false`) и запоминает последний размер окна для клиента.
- Поддерживает светлую и тёмную темы Foundry.

### Боезапас

- Ёмкость берётся из поля дальней атаки **Shots** (в русской локализации —
  **«Бзс»**), ключ данных `system.ranged.<key>.shots`. Код не зависит от языка
  интерфейса: подпись может быть любой, используется только ключ данных.
- Если у оружия `Shots` пустой, `T` или `0` — трекер **не создаётся**.
- Для оружия с непустым `Shots` создаётся штатный GURPS Resource Tracker
  с именем `Боезапас: <оружие>` / `Ammo: <weapon>`.
- Ёмкость парсится из GURPS-нотации:
  - `30+1(3)` → 31;
  - `30(3)` → 30;
  - `3(3)` → 3;
  - `1(2)` → 1.
- При атаке:
  - `RoF <= 1` — списывается 1 патрон;
  - `RoF > 1` — списывается число, выбранное в системном диалоге
    «Количество выстрелов»; по умолчанию в диалоге стоит **1**, чтобы
    случайно не получить бонус за очередь;
  - если патронов меньше скорострельности, диалог и сама атака ограничиваются
    остатком боезапаса;
  - при нуле патронов атака блокируется с подсказкой **«Кончился боезапас»**;
  - если после выбора патронов всё же не хватило, списывается остаток до 0.
- Если у дальней атаки задан статический уровень навыка без привязки к
  скиллу (пустой OTF), модуль восстанавливает потерянный системой `import`
  и `level` из данных предмета, чтобы в листе не появлялся `NaN`.
- В карточке «Боезапас» название оружия остаётся прежним, а рядом можно
  записать **тип боеприпаса** (например, «AP», «трассер», «дробь»). Значение
  хранится в flags актора и не меняет имя Resource Tracker.
- Для любой строки можно выбрать **предмет-запас патронов** — другой предмет
  актора с количеством (`system.eqt.count`). Это не заменяет магазин: текущий
  и максимальный боезапас по-прежнему хранятся в Resource Tracker оружия.
- Если запас привязан, кнопка сброса работает как **перезарядка**: она
  доливает недостающие патроны до максимума магазина и вычитает заряженное
  количество из `count` предмета-запаса. Если запаса не хватает, магазин
  заполняется на доступное количество, а в запасе остаётся 0.
- Привязка не удаляет и не изменяет предмет-запас; при снятии привязки
  перезарядка перестаёт списывать патроны из него.
- У каждой строки есть кнопка **удаления трекера**: она удаляет привязку и
  Resource Tracker этого актора, не удаляя оружие и предмет-запас.
- Для старых «осиротевших» трекеров в заголовке карточки есть кнопка
  **массовой очистки** (метла): она удаляет все трекеры с именем боезапаса,
  которые больше не привязаны ни к одному оружию.
- Автоматическое создание выполняется один раз при первом открытии актора
  и при добавлении нового оружия; при изменении уже существующего оружия
  обновляется его привязка, но вручную удалённый трекер не возвращается.
  Вернуть трекер можно кнопкой синхронизации.
- При синхронизации, перезарядке и удалении трекеров сохраняется позиция
  прокрутки вкладки «Бой», чтобы лист не прыгал к началу.
- В тёмной теме выпадающий список предметов-запасов оформлен тёмным фоном
  с светлым текстом.
- В modern-листе персонажа во вкладке **«Бой»** появляется карточка
  «Боезапас» с полями текущего и максимального значения, кнопкой сброса
  и кнопкой повторной синхронизации.
- Изменение максимума вручную помечается как пользовательское и больше не
  перезаписывается при изменении `Shots` предмета.
- Трекеры также видны в штатной вкладке «Заметки» modern-листа и в старом
  листе персонажа — это дополнительные точки ручного редактирования.

### Изоляция по персонажам

- Все трекеры и привязки хранятся **у конкретного актора**.
- Ключ привязки — встроенный `Item.id` этого актора, а не `globalid`
  world-item и не UUID world-item.
- Если у нескольких персонажей лежат копии одного и того же world-item,
  удаление оружия у одного персонажа удаляет **только его** трекер.
  У остальных персонажей оружие и боезапас не меняются.
- Переименование или удаление world-item из сайдбара Items не затрагивает
  встроенные копии и трекеры акторов.
- При переносе оружия с одного актора на другого на исходном трекер удаляется,
  на новом создаётся заново (текущее значение при переносе не сохраняется).

### Совместимость

- Если активен **GGA Ammunition & Resource Assistant** и атака запущена его
  workflow, модуль не списывает патроны повторно.
- Обычные атаки с листа персонажа при этом продолжают учитываться модулем.
- `libWrapper` не требуется.

## Установка

1. Скопируйте папку `gurps-item-modern` в
   `...\FoundryVTT\Data\modules\gurps-item-modern`
   (в этой рабочей копии уже создана junction-ссылка на проект).
2. Запустите Foundry VTT, откройте мир на системе **gurps**.
3. Включите модуль в списке модулей мира и перезагрузите мир (F5).
4. Откройте предмет: Items в сайдбаре или предмет у актора
   (при включённой настройке GURPS «Use Foundry Items»).
5. Откройте modern-лист персонажа → вкладка **«Бой»** — под таблицей дальней
   атаки появится карточка «Боезапас», если у оружия заполнено «Бзс» (Shots).

## Настройки модуля

- **Автоматически создавать трекеры боезапаса** (по умолчанию включено).
  Отключение запрещает создание новых трекеров; существующие привязки
  продолжают работать.
- **Блокировать атаку без патронов** (по умолчанию включено). При нулевом
  боезапасе бросок атаки не выполняется до перезарядки.
- **Учитывать внешние модули боезапаса** (по умолчанию включено). Не списывать
  патроны повторно, когда GGA Ammunition & Resource Assistant выполняет свой
  сценарий стрельбы.

## Требования

- Foundry VTT 13–14 (проверено на 14.369).
- GURPS 4e Game Aid 0.18.x (проверено на 0.18.24).

## Ограничения

- Автоматические трекеры создаются для **Foundry-предметов** типа `equipment`
  с дальней атакой, а также для **прямых дальних атак** типа `rangedAtk` без
  родительского equipment-предмета. Старые компоненты актора без предмета
  не отслеживаются.
- Один общий магазин на предмет оружия. Если в одном предмете несколько
  независимых магазинов (например, подствольник), они будут использовать общий
  максимум; для такого оружия лучше вести отдельные трекеры вручную.
- `30+1(3)` считается как 31 (магазин + патрон в патроннике). Максимум всегда
  можно поправить вручную в карточке «Боезапас».
- При переносе оружия на другого актора текущий боезапас не переносится:
  на новом акторе создаётся полный магазин.
- Удаление оружия удаляет только трекер этого актора. Копии оружия и их
  трекеры у других акторов не затрагиваются.
- При очистке `Shots` (Бзс) у предмета его трекер и привязка удаляются.
- Карточка «Боезапас» добавляется только в modern-лист; в старом листе
  используются штатные Resource Trackers.
- Разметка листа предмета не меняется: визуальная часть приводит её к палитре
  Modern-листа, но не пересобирает форму.
- Начальная высота окна предмета фиксированная (760×720 по умолчанию) — иначе
  Foundry не даёт тянуть окно по вертикали при `height: "auto"`.
- Минимальный размер окна предмета — 680×420.
- Если в будущей версии GURPS переименует класс листа предмета
  (`gurps.GurpsItemSheet`), модуль попробует найти его по имени класса или
  шаблону. Если не найдёт — просто не активируется и напишет предупреждение
  в консоль, не ломая игру.

│     ├─ attack.mjs            # обёртка атаки, диалог выстрелов, списание

├─ tests/
│  ├─ smoke.mjs                # проверка патча листа предмета без Foundry

## Разработка

Скриншоты: `tests/preview-light.png`, `tests/preview-dark.png`,
`tests/preview-actor-light.png`, `tests/preview-actor-dark.png`.

- `node tests/smoke.mjs` — проверяет патч листа предмета, ресайз и сохранение
  размера окна.
- `node tests/ammo.test.mjs` — проверяет парсинг «Бзс»/RoF, создание трекеров,
  изоляцию по акторам, удаление оружия, перенумерацию трекеров, ручной максимум,
  восстановление уровня дальней атаки, тип боеприпаса, привязку к предмету-запасу
  патронов, перезарядку из запаса, удаление осиротевших трекеров, списание
  выстрелов и обёртку атаки (включая внешний ammo-assistant workflow, лимит по
  остатку и сообщение «Кончился боезапас»).
- `tests/preview.html` — статический preview листа предмета.
- `tests/preview-actor.html` — статический preview карточки «Боезапас» в
  modern-листе. Оба стенда подключают `foundry2.css`, `gurps.css` и CSS модуля
  с локального диска, поэтому пути в них привязаны к этой машине.
  Параметры: `?dark=1`, `?small=1`, `?debug=1`.
